# 旅记 TripFlow


一个出行计划工具 - 把分散在小红书收藏夹里的吃喝住行攻略，整合成一个可调整的行程时间轴。

## 解决什么问题

做出行攻略时，我们会在小红书刷到很多景点、餐厅、拍照角度，随手收藏后堆在收藏夹里混乱不堪。到了景点现场，想找"那个地方有什么角度出片"完全找不到。

**TripFlow** 把这些零散的收藏整理成：
- 按 **城市 / 类型** 分类的卡片墙（景点、餐厅、住宿、其他）
- 每张卡片可记录 **出片指南**（角度、姿势、技巧）
- 可拖拽调整顺序的 **行程时间轴**
- 当天路线的 **地图可视化**（景点间连线 + 距离参考）

## 快速开始

**`https://qiuuuyanping.github.io/-TripFlow/tripflow.html`** 
即可在浏览器中打开使用，无需安装任何东西。
这是单文件版本，所有 JS 都内嵌在 HTML 里，不依赖外部文件。

## 功能说明

### 📋 出行概览
- 出行标题、日期、天数、途经城市
- Visa 卡 / 现金支付提醒
- 签证、货币信息
- 各城市收藏统计

### ⭐ 我的收藏
- 按城市分组的卡片墙
- 多种类型：景点  / 餐厅  / 住宿  / 其他 
- 每张卡片包含：名称、地址、坐标、备注、**出片指南**、标签
- 支持增删改

### 📅 行程时间轴
- 按天规划行程
- 每个行程绑定一个收藏项
- **可拖拽调整顺序**（拖动 ⠿ 图标）
- 显示与下一站的距离参考
- 按时间自动排序

### 🗺️ 地图路线
- 使用 Leaflet + OpenStreetMap（免费、无需 API key、全球覆盖）
- 当天行程的景点在地图上标号显示
- 景点间虚线连线
- 点击标记查看详情（含出片指南）
- 路线列表 + 总距离参考

## 数据存储

所有数据存在浏览器 **localStorage** 中，不依赖后端。
- 数据只存在当前浏览器，换设备/清缓存会丢失
- 概览页提供"恢复示例数据"和"清空所有数据"按钮

## 示例数据

内置一份"罗马3日游"示例数据，包含：
- 8 个收藏（斗兽场、梵蒂冈博物馆、特莱维喷泉、万神殿、圣天使堡、2家餐厅、1家酒店）
- 3 天完整行程安排
- 每个景点都有出片指南

## 文件结构

```
/workspace
├── tripflow.html   # ⭐ 单文件版（双击直接打开，推荐！）
├── index.html      # 页面骨架（需配合 app.js 使用）
├── app.js          # 全部应用逻辑（~1000 行）
└── README.md       # 本文档
```

> **为什么有两个版本？**
> - `tripflow.html` = 单文件版，JS 内嵌在 HTML 里，**双击就能打开**
> - `index.html` + `app.js` = 分离版，需要通过本地服务器打开（直接双击会被浏览器 CORS 拦截）
> - 日常使用选 `tripflow.html`；要改代码时选分离版更好维护
